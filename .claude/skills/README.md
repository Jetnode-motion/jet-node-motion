# Скиллы проекта

Подключены из поста theskibap («Бесплатные скиллы Claude, которые убивают ИИ-слоп», 18.10.2026). Каждая папка скопирована из исходного репозитория вместе с его лицензией.

| Скилл | Зачем нам | Источник | Коммит |
|---|---|---|---|
| `impeccable` | Шлифовка кадров на HTML/React: иерархия, отступы, типографика, цвет, анимация | [pbakaus/impeccable](https://github.com/pbakaus/impeccable) (Apache 2.0) | `2f46b7a` |
| `taste-skill` | Когда кадр выглядит шаблонно: вкус и арт-дирекция | [Leonxlnx/taste-skill](https://github.com/Leonxlnx/taste-skill) (MIT) | `a206bbf` |
| `humanizer` | Текст на экране, субтитры, посты: убрать «нейросетевое» звучание | [blader/humanizer](https://github.com/blader/humanizer) (MIT) | `8c307f3` |
| `stop-slop` | То же для любых текстов: меньше воды и шаблонных оборотов | [hardikpandya/stop-slop](https://github.com/hardikpandya/stop-slop) (MIT) | `8da1f03` |

Фирменный стиль, на который эти скиллы должны опираться: `knowledge-base/style-guide.md` в файлах проекта и `src/style/tokens.ts`.

Чтобы обновить скилл, склонируй его репозиторий и замени папку целиком.
